# Credits

## Narration

Synthesized with [ElevenLabs](https://elevenlabs.io) using library voices *Pangge* (Chinese) and *Michael Dan* (English), model `eleven_v4`. The audio files are not included in this repository; regenerate them with `./run.sh letting-go tts` (subject to ElevenLabs' terms).

## Fonts (SIL Open Font License 1.1, bundled as subsets in `fonts/`)

| File | Font |

| `brush.ttf` | Ma Shan Zheng 马善政楷书, via Google Fonts |
| `kai.ttf` | LXGW WenKai 霞鹜文楷 |

Seal characters use Noto Serif CJK from the system.

## Text

The copybook lines come from 《声律启蒙》 (Qing dynasty, public domain). The narration is adapted from the essay 《提示词演进史》.
