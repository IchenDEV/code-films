# 凡人 · 抖音版

> 科学把我们从神坛上，请下来过三次。第三次，正在发生。

《凡人 · Ordinary》（约 6 分钟，16:9）的抖音竖屏版：**9:16 · 1:49 · 中文**。▶ [观看](https://github.com/IchenDEV/code-films/releases/download/ordinary-v1.0/ordinary-douyin-zh.mp4)成片 `out/deliver/凡人_抖音.mp4`，发布用的标题、简介、话题与置顶评论见 [发布文案.md](发布文案.md)。

## 和原片的关系

- **画面是原片镜头的重新剪辑。** 原片的镜头函数（`../shots/*.js`）原样复用，不改一行：每个画面段落从原片某个镜头里取一段（`script.mjs` 的 `SEGS`：`src` 镜头、`from`/`to` 原片镜头内的秒数），按新旁白的实测长度快放（多数 1.1～2.4 倍）。镜头读到的 `sh`、`dur` 仍是原片时间轴（`../timeline_zh.json`）里的，所以闪电、剪辑点、屏幕逐字这些镜头内的对位都不变。两处用 `sync` 把原片镜头里的变化（回顾里换图、人走下神坛）对到新旁白念到关键词的那一刻。
- **不用裸体人像。** 平台审核可能误判古典名画里的裸体：原片的《维特鲁威人》换成天圆地方（天地正中一个“人”字），《创造亚当》从平移之后开始、只取两只手和上帝一侧。
- **竖屏取景。** 原片镜头先画在 1920×1080 的横屏画布上（带原片的暗角与颗粒），再按 `w`（露出的横向宽度）、`cx`/`cy`（取景中心）裁进竖屏的画面框。原片里写在画面上的小字在手机上看不清，所以关键数字（1400 年、几千亿、约 11 秒、98.8%、47 / 19 / 4 / 2 年）和三次章节（第一次 · 位置、第二次 · 出身、第三次 · 心智）在念到时用大字砸出来。
- **旁白重写。** 原片 6 分钟的稿子压成约 480 字的口播：第一句就是钩子（“请下来过三次，第三次正在发生”），片尾兑现，再让观众在评论区选最难接受的一次。先写初稿与简报（`brief/narration-brief.md`），交给 Gemini 改口语节奏（`brief/narration-gemini.mjs`），再逐句改回：Gemini 稿压得太书面（“一信一千四百年”“巨链里，我们紧靠天使”），也有听不懂的说法（“下出第三十七手”）；保留了它的“说白了”加一声叹气、图灵一句的好奇语气、“到头来”，以及“AI 胜过大多数人”这一分寸。事实全部取自原片稿（出处见 [../CREDITS.md](../CREDITS.md)），没有加新的事实。
- **配音换人。** 原片中文是 Haoran；这一版用 Pangge（Eleven v4，稳定性 0.4、表现力 0.3），整条一次合成，只在段落之间的静音里下刀。多音字：“长成”“配乐”“一九五〇”只在送给合成的文本里换成同音字（`SAY`），字幕不变。整条转写吻合 0.990；转写漏掉的四处年份单独截出来再转写，确认都念了（Scribe 转长音频时会吞掉汉字数字）。
- **配乐与音效。** ElevenLabs Music 按六个段落作曲（D 小调管弦：神坛古老、位置展开、出身温暖、心智加速、结论最宽）。默认种子那一版在“出身”一段空了 22 秒，种子 7、11 开场太弱，用的是种子 23。音效 8 个（切画面的风声、章节落地的重击、数字的闷击、蓝点的闪烁、“AI 做的”之前的上升音、“凡人”的一声钟）。混音 -14 LUFS，检查掉空 0 处、跳变 0 处。

## 制作

在仓库根目录：

```bash
./run.sh ordinary/douyin tts        # 旁白整条合成、转写核对，并排时间轴（需要已登录的 elevenlabs CLI）
./run.sh ordinary/douyin music      # 作曲 + 轮廓检查 + 铺底长音
./run.sh ordinary/douyin sfx        # 音效库
./run.sh ordinary/douyin mix        # 混音 → out/mix/douyin.wav，检查掉空与跳变
./run.sh ordinary/douyin render     # → out/deliver/凡人_抖音.mp4
./run.sh ordinary/douyin extras     # → SRT 字幕与封面
./run.sh ordinary/douyin stills @ptolemy%80 @endcard+3 --sheet
./run.sh ordinary/douyin preview
```

## 文件

| 文件 | 内容 |
|---|---|
| `script.mjs` | 旁白（逐句的段落、画面段落、关键词、语气标签）、读音替换、画面段落表（取原片哪个镜头的哪一段、怎么裁、砸什么字）、画面文字 |
| `index.html` | 竖屏页面；`<base href="../">` 让原片的镜头、档案图和时间轴按原片目录加载 |
| `web/main.js` | 竖屏合成：原片镜头 → 横屏画布 → 画面框；常驻标题与进度条、逐字高亮字幕、大字、档案图说、片尾互动卡 |
| `tools/tts.py` · `timeline.mjs` | 整条合成与切段；时间轴（含原片镜头内的时间锚点） |
| `tools/music.py` · `sfx_gen.py` · `bed.py` · `mix.py` | 配乐、音效、铺底、混音 |
| `tools/contour.py` · `check_audio.py` | 配乐轮廓、成片音频连贯性检查 |
| `tools/render.mjs` · `stills.mjs` · `extras.mjs` · `remux.sh` | 渲染交付（中途被打断时 `--resume` 只补渲缺的帧）、截帧、字幕与封面、只换音轨 |
| `brief/` | 旁白简报与 Gemini 改写稿 |
