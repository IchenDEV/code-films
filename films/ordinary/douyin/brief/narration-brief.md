# 《凡人》抖音版旁白简报

## 任务

把下面的初稿改成适合抖音竖屏短视频的中文口播稿。原片是 6 分钟的纪录片《凡人 · Ordinary》（全文见 `../../script.mjs` 的 `LINES`，每条的第一个字符串是中文）。抖音版约 95～105 秒，画面复用原片镜头，旁白重写。

配音：ElevenLabs Eleven v4，中文男声 Pangge，stability 0.4 / style 0.3，整条一次合成。实测语速约 4.4 字/秒（含停顿）。

## 要求

1. **总字数 400～450 字**（不含标点、不含语气标签）。单句 ≤ 32 字，一句最多两个逗号停顿。
2. **口语，像一个人在跟朋友讲一件让他震撼的事**；不要播音腔，不要网络腔（不用“家人们”“宝子们”“绝了”）。可用少量语气词（“你看”“说白了”“结果呢”“好家伙”），全篇 ≤ 4 处。
3. 注意平仄与句尾声调交替、重音靠句式托出（破折号前蓄力、关键词放句尾）、断句处给呼吸。
4. 可选 Eleven v4 语气标签，全篇 ≤ 3 个，只能用 `[thoughtful]` `[curious]` `[chuckles]` `[sighs]` `[warmly]`，不用 `[excited]`。
5. **第一句就是钩子**（0.1 秒开口），必须抛出“科学把人从神坛上请下来过三次，第三次正在发生”这一悬念，片尾兑现。
6. 结构固定（act 不能改，镜头 shot 只能从初稿里给出的 shot 名里选，顺序不变）：hook → altar（神坛）→ one（第一次·位置）→ two（第二次·出身）→ three（第三次·心智）→ end（结论 + 互动）。
7. 片尾互动一句：让观众在评论区打 1、2、3，选三次里最难接受的一次。

## 多音字禁区（Pangge 容易读错）

不用：行（一行、行业）、得（děi）、干（干活）、重（重复、看重）、还是 / 还会、数（数以…）、调、处、间隔、差（chā / chà 易混）、长（cháng / zhǎng 易混；若必须保留“长成一棵树”，标出来，我会做读音替换）、了解（liǎo）、为（wèi / wéi 易混）。年份写汉字（一五四三年），百分数写汉字（百分之九十八点八）。英文名 AlphaGo、AlphaFold、DNA、AI 前后留空格。

## 交付格式

写到 `films/ordinary/douyin/brief/narration-gemini.mjs`，内容是一个 JS 模块：

```js
export const DRAFT = [
  { act: 'hook', shot: 'descend', zh: '……', tag: '[thoughtful]' /* 可省略 */, k: ['关键词子串', …] },
  …
];
```

- 每条一句，shot 只能用初稿里出现过的名字，顺序按初稿；可以把两条合并成一条，或把一条拆成同一 shot 的两条。
- `k`：这一句里 1～2 个需要画面“砸字”的关键词，必须是 zh 的原文子串。
- 文件末尾用注释写：总字数（不含标点与标签）、改动理由（各一句）、哪些字需要读音替换。

只写这一个文件，不改仓库里别的文件。
