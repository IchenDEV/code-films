> 我不再亲手给 AI 派活了，现在是 AI 管 AI。

根据 IDEVLAB 原创文章《写程序，越来越像治理一个组织》制作：从亲手写函数，到像技术负责人一样给 Agent 拆任务、做审查、给 Agent 劝架，再到让 Agent 管 Agent。当管理几千人的领导不会亲手审每个 PR，写程序也开始变成维护一套让工作自主运转的机制——拆不拆任务、拿什么算完成证据、痛觉越级报警，以及在死循环时改机制而不是给提示词打补丁。短版聚焦个人视角的组织演进故事线，长版完整梳理 8 本管理学经典（西蒙、明茨伯格、格鲁夫、比尔、梅多斯、巴纳德等）的现代映射。一套亮色的包豪斯海报风画面出三个成片（抖音、视频号、B 站），旁白与配乐由 ElevenLabs 生成。
